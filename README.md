# Счёт за созвон

Интерактивный сервис для оценки стоимости рабочего времени на встречах. Проект № 01 серии «В каждой бочке».

**Работающий сервис:** https://siblife54-dot.github.io/howmuchsozvon/

## Возможности

- SVG-переговорная с анимированным размещением до 12 участников; редактирование по нажатию на аватар или через список команды.
- Зарплаты с точностью до копейки, длительность 5–240 минут, 0–100 встреч в месяц, изменяемая норма 1–744 рабочих часов.
- Стоимость встречи, месяца, года и человеко-часы. Десятичная арифметика `decimal.js`, округление только для отображения.
- Сравнение двух переговорных: независимый исходный снимок, исключение и возврат участников, изменения параметров и зарплат только в сценарии ПОСЛЕ, сброс оптимизации.
- Корректное отображение роста стоимости, нулевых сумм и неопределённого процента при нулевой исходной стоимости.
- PNG-чек через Canvas с локальными шрифтами и кириллицей, системное меню «Поделиться», копирование текста. Чек не содержит имён и персональных зарплат.
- Сохранение расчёта и сравнения в localStorage с проверкой загружаемых данных. Обработка отказа хранилища и буфера обмена.
- Мобильная компоновка, клавиатурное управление, нативные модальные окна с удержанием фокуса, `prefers-reduced-motion`.

## Локальный запуск

Node.js 24 LTS и npm:

```sh
npm ci
npm run dev
```

Сборка и предпросмотр production-версии:

```sh
npm run build
npm run preview
```

## Проверки

```sh
npm test
npm run test:e2e
```

Unit-тесты проверяют контрольные расчёты, дробные суммы, нули, снимки сценариев, рост стоимости, проверку сохранённых данных и приватность текста чека.

Браузерные тесты Playwright используют установленный Microsoft Edge (`channel: msedge`). Для другой ОС установите Edge (`npx playwright install msedge`) или замените channel в `playwright.config.ts` на установленный Chromium. Они проверяют редактирование, добавление, удаление, перезагрузку, сравнение, PNG, буфер обмена и ширины 320 / 390 / 1440 px. Скриншоты и пример PNG сохраняются в `../../outputs` относительно проекта; это путь для локальной рабочей среды, его можно изменить в `tests/app.spec.ts`.

## GitHub Pages

В репозитории: **Settings → Pages → Build and deployment → Source → GitHub Actions**.

Workflow `.github/workflows/deploy.yml` при каждом push в `main` выполняет `npm ci`, тесты, production-сборку и публикацию артефакта `dist`. Запуск также доступен вручную через Actions. Относительный `base: './'` в Vite обеспечивает загрузку ресурсов из `/howmuchsozvon/`. Роутера и серверных маршрутов нет.

Если GitHub Pages ещё не включён, первый workflow может остановиться на `configure-pages`. После выбора источника GitHub Actions запустите его повторно.

## Данные и расчёт

Имена и зарплаты не отправляются на сервер. Приложение не использует аналитику, API, внешние шрифты, регистрацию или базу данных. Хостинг получает обычные запросы файлов приложения; содержимое расчёта остаётся в браузере. На общем устройстве очистите данные сайта после использования.

Стоимость часа = зарплата ÷ рабочие часы. Встреча = сумма часовых ставок × минуты ÷ 60. Месяц = встреча × частота. Год = месяц × 12. Человеко-часы = участники × минуты ÷ 60 × частота.

Это оценка стоимости рабочего времени по зарплатам. Она не включает налоги работодателя, накладные расходы и полезность встречи. Высвобождение времени не означает автоматического уменьшения расходов на зарплаты.

Шрифты Manrope и IBM Plex Mono поставляются локально через Fontsource с их лицензиями OFL в соответствующих npm-пакетах. React, TypeScript, Vite, Motion, Lucide и Decimal.js — зависимости проекта; сервер для приложения не требуется.
